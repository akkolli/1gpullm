### 1 GPU LLM


This repo will contain my work on optimizing, pretraining and finetuning a small local llm.
It is mostly educational is nature, and will contain a worklog of the tricks I try and the effects they have on the LLM.
The LLM will be trained on a 5090, so all architectural decision will take place with that in mind.

All runs need to be finish under an hour on my 5090, eval on the CoreWebText val set.
